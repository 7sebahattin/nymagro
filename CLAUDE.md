# Git / PR İş Akışı

Bu depoda çalışırken aşağıdaki kurallara uy.

## Branch ve push

- Değişiklikleri asla doğrudan `main` üzerinde yapma. Her görev/özellik için ayrı bir branch oluştur (örn. `claude/<konu-adı>`).
- `git push -u origin <branch-adı>` kullan.
- Push ağ hatasıyla başarısız olursa 4 kez üstel geri çekilmeyle (2s, 4s, 8s, 16s) yeniden dene.
- `--force`, `--no-verify`, `--no-gpg-sign` gibi bayrakları kullanıcı açıkça istemedikçe kullanma.

## Pull Request

- Kullanıcı açıkça istemedikçe PR açma.
- PR açarken repoda bir PR şablonu varsa (`.github/pull_request_template.md` vb.) onun başlıklarını kullan.
- Bir PR merge edildikten sonra: o PR bitmiştir, üzerine yeni commit ekleme. Ek/ardıl iş için `main`'den yeni bir branch aç ve gerekirse yeni bir PR oluştur.
- Bir review'da (ör. otomatik reviewer) bulunan ama PR merge olduktan **sonra** düzeltilen bulgular için: mevcut (merge edilmiş) PR'ı asla yeniden açma; düzeltmeleri `main`'den açılan yeni bir branch/PR olarak gönder.

## PR izleme (subscribe_pr_activity)

- Kullanıcı bir PR'ı izlememi/otomatik düzeltmemi istediğinde `subscribe_pr_activity` kullan.
- Kendi açtığım PR'larda "drive-to-green" tutumu geçerlidir: her CI hatası olayında ya bir düzeltme push'la ya da neden düzeltmediğimi açıkla — sessizce bırakma.
- Kullanıcının izlememi istediği (kendi açmadığım) PR'larda: küçük ve net olanları düzelt, belirsiz/mimari olanları `AskUserQuestion` ile sor, aksiyon gerektirmeyenleri sessizce geç.
- Webhook olayları CI başarısını, yeni push'ları veya merge-conflict geçişlerini her zaman güvenilir şekilde iletmez. Bu yüzden `send_later` ile yaklaşık 1 saatte bir kendime check-in mesajı zamanla; PR durumunu tekrar kontrol et, değişiklik yoksa sessizce yeniden zamanla (kullanıcıya mesaj atma).
- PR merge/close olduğunda `unsubscribe_pr_activity` otomatik/manuel tetiklenir; bu noktadan sonra o PR için tekrar check-in zamanlama, yeni PR açma veya eski PR'ı yeniden açma — bitmiş sayılır.

## Commit mesajı / attribution

- Commit mesajlarına model kimliğini (ör. "claude-sonnet-5") yazma; bu sadece sohbet içi kullanım içindir.
- Commit'lerin sonuna şu satırları ekle:

```
Co-Authored-By: Claude <noreply@anthropic.com>
```

- GitHub'a atılan her yorum/PR açıklaması/review reply'nin sonuna şu attribution footer'ı ekle:

```
---
_Generated by [Claude Code](https://claude.ai/code)_
```
